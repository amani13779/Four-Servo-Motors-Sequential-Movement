# Four Servo Motors Sequential Movement

## Overview
This project demonstrates controlling four servo motors using an Arduino Uno in **Tinkercad**. The motors perform two sequential movements: first, they execute a sweep motion for exactly two seconds, then they stop and remain fixed at a **90°** position.

## Project Objectives
- Control four servo motors simultaneously.
- Perform a sweep motion for exactly two seconds.
- Stop the sweep automatically after the specified duration.
- Set all servo motors to a fixed position of 90°.

## Components Used
- Arduino Uno
- 4 Servo Motors
- Jumper Wires

## Software Used
- Tinkercad
- Arduino IDE

## Project Files
- `servo_movement.ino` – Arduino source code.
- `servo_demo.mp4` – Demonstration video of the project.
- `README.md` – Project documentation.

## How It Works
1. Four servo motors are connected to the Arduino Uno.
2. All motors perform a synchronized sweep movement for two seconds.
3. After the two-second interval, the sweep stops automatically.
4. All servo motors move to a 90° position and remain there.

## Output
- All four servo motors move together between 0° and 180° for two seconds.
- After the sweep ends, every servo stops and stays at the 90° position.
